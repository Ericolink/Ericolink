# ¡Hola, soy Eric! 👋

Full-stack developer en Ciudad Juárez, próximo a titularme en Ingeniería en Desarrollo y Gestión de Software (UTCJ). Construyo aplicaciones completas de principio a fin — desde la base de datos hasta la interfaz — y disfruto meterme a fondo en cada capa del stack.

- 🔭 Actualmente construyendo **PaseLink**, una plataforma de gestión de eventos y check-in por QR
- 💼 Terminando mi servicio profesional en **Triomphe Bienes Raíces**, donde desarrollé una plataforma de remates inmobiliarios desde cero
- 🛠️ Mantengo mi propio homelab con Docker, Cloudflare Tunnel, Nginx Proxy Manager y CI/CD self-hosted
- 🌱 Aprendiendo constantemente sobre arquitectura backend, DevOps y buenas prácticas de UX
- 💬 Hablo español (nativo) e inglés (B2)
- 📫 Contáctame por LinkedIn o GitHub
